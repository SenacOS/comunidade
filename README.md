# 💬 SenacOS · Comunidade

Este repositório é o fórum oficial da comunidade SenacOS — o espaço pra tirar dúvida, avisar algo, trocar ideia ou mostrar o que você andou construindo, sem misturar isso com as Issues de projetos sérios sendo avaliados.

Aqui não tem Issues, só Discussions. Se você chegou aqui procurando abrir uma Issue de bug ou sugestão de um projeto específico, é no repositório desse projeto que ela deve ser aberta — este espaço é só pra conversa.

## 📂 Categorias

| Categoria | Pra que serve |
| --- | --- |
| 📢 **Avisos** | Comunicados oficiais da organização, professores ou moderadores — editais, eventos, mudanças de processo. Abertura de novo tópico aqui é restrita à moderação; qualquer um pode comentar. |
| 💬 **Bate-papo** | Conversa livre da comunidade — sem formulário, sem formalidade. Papo livre sobre qualquer assunto. |
| ❓ **Dúvidas** | Perguntas técnicas ou sobre a organização que não são bug de nenhum projeto específico. Use o formulário estruturado — ele já te guia a dar contexto suficiente pra alguém conseguir ajudar. |
| ⚗️ **Projetos** | Espaço pra divulgar um projeto pessoal ou acadêmico que você quer compartilhar (não precisa ser um `[CURSO]-[SEMESTRE]-*` da organização). Use o formulário estruturado. |
| 🗳️ **Votações** | Participe das pesquisas e decisões da comunidade. Espaço dedicado para enquetes e escolhas coletivas. |

## 🤔 Como participar

* **Busque antes de perguntar:** Veja se sua dúvida/assunto já não foi discutido usando a barra de busca antes de abrir um tópico novo.
* **Selecione o espaço correto:** Escolha a categoria certa (evita ficar "boiando" sem resposta).
* **Siga os templates:** Se a categoria tiver formulário (**Dúvidas**, **Projetos**), preencha os campos — isso ajuda muito quem for responder.
* **Seja respeitoso:** As regras de conduta da organização ([`CODE_OF_CONDUCT.md`](https://github.com/SenacOS/.github?tab=coc-ov-file), herdado do repositório [`.github`](https://github.com/SenacOS/.github)) valem aqui como em qualquer repositório da SenacOS.
* **Peça ajuda:** Travou numa dúvida mais técnica e ninguém respondeu? Marque `@SenacOS/professores` no tópico.

## 🔒 Privacidade

Este é um repositório público e indexável. Evite postar dados sensíveis (CPF, endereço completo, telefone pessoal) em qualquer tópico, mesmo em **Bate-papo**.

## 🛡️ Moderação

Integrantes de `@SenacOS/professores` têm permissão para fechar, mover de categoria ou converter em resposta tópicos fora do propósito do espaço. Conteúdo que violar o Código de Conduta é removido sem aviso prévio.

> Dúvidas sobre como a organização funciona? Veja o **Guia de Contribuição** no repositório [`core`](https://github.com/SenacOS/core).
